⚙️ System ComponentsMicrocontroller: Arduino Uno  Sensors: Soil Moisture Sensor (measures volumetric water content), Temperature & Humidity Sensor.  Actuators: 12V Solenoid Valve (controls water flow) via a Driver Relay module.  Display: 16x2 LCD Screen (displays live moisture levels & valve status).  Power Supply: External power reference for Arduino and the high-current solenoid system.  🛠️ Hardware Connection LogicInputs: Soil Moisture analog/digital pins connected directly to the Arduino interface.  Control Output: Arduino digital pin toggles the Relay Module (HIGH / LOW).Power Loop: The relay acts as an automated switch controlling the external power running through the Solenoid Valve.  Feedback: The I2C/Standard LCD displays real-time system states.
